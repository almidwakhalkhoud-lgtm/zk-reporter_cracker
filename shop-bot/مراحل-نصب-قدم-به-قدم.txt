نصب ربات گزارش تردد روی سیستم مغازه — قدم به قدم
==================================================

■ مرحله ۱ — کپی پوشه
  پوشه shop-bot را کپی کنید در:  C:\shop-bot
  (۵ فایل: bot.py, config.json, install.bat, run.bat, راهنمای-نصب.txt)

■ مرحله ۲ — نصب پایتون
  1) Start → تایپ cmd → Enter
  2) دستور:
       winget install -e --id Python.Python.3.12
     (اگر سوال کرد Y بزنید)
  3) CMD را ببندید و یک CMD جدید باز کنید (مهم!)
  4) تست:
       python --version
     باید Python 3.12.x نشان دهد.
  * اگر winget خطا داد: از python.org/downloads نصب کنید و
    حتماً تیک «Add python.exe to PATH» را بزنید.

■ مرحله ۳ — نصب کتابخانه دستگاه
       pip install pyzk
     باید آخرش Successfully installed بنویسد.

■ مرحله ۴ — تست دیدن دستگاه (اختیاری)
       ping 192.168.100.207
     باید Reply بدهد.

■ مرحله ۵ — نصب ربات
  1) در C:\shop-bot روی install.bat دوبار کلیک کنید
  2) اگر پنجره آبی ویندوز آمد: More info → Run anyway
  3) آخر کار باید بنویسد: «ربات شروع شد — دستگاه 192.168.100.207:4370»
  4) اگر فایروال پنجره داد: Allow access

■ مرحله ۶ — تست از تلگرام (گوشی ادمین)
  1) سرچ: @Mehdialitrading_bot → Start
  2) دکمه «وضعیت دستگاه» → باید سریال BAY5244401243 را نشان دهد
  3) دکمه «گزارش کامل» → باید فایل اکسل بیاید

■ مرحله ۷ — تست اجرای خودکار
  1) پنجره CMD ربات را ببندید
  2) سیستم را Restart کنید
  3) یک دقیقه بعد از بالا آمدن ویندوز، از تلگرام یک دکمه بزنید
  4) اگر جواب داد، همه‌چیز تمام است — از این به بعد خودکار است.

■ رفع اشکال
  - ربات جواب نمی‌دهد → اینترنت سیستم را چک کنید؛ run.bat را دستی اجرا
    کنید و خطا را ببینید.
  - «دستگاه در دسترس نیست» → ping 192.168.100.207 و کابل شبکه دستگاه.
  - سایر خطاها → فایل C:\shop-bot\bot.log را بفرستید.
